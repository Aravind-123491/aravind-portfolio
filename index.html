RECENT PROJECT

ATTENDANCE LOG

Full-Stack SaaS Platform

The Problem: Managing attendance across multiple branches manually was causing massive data entry errors and "buddy punching" (proxy attendance).

The Solution: I developed a multi-tenant SaaS platform where institutions can manage their own users. It features a React.js web dashboard for administrators to generate reports, and a native Android app (Kotlin) for employees. To ensure authenticity, I integrated GPS geofencing (preventing check-ins from outside the office perimeter) and dynamic QR code scanning.

Impact: Reduced manual HR workload by 80% and completely eliminated proxy attendance for the pilot client.

React Node.js MySQL Android (Kotlin) REST APIs

FINAL YEAR PROJECT

DRUG RESPONSE PREDICTION

Machine Learning Model

The Problem: In clinical trials, prescribing the right drug dosage often relies on trial-and-error, which can be dangerous and time-consuming for patients with specific genetic profiles.

The Solution: I built a predictive Machine Learning model using Python and the Random Forest algorithm. I handled a massive dataset containing genetic markers and clinical history, performing extensive Data Preprocessing and Feature Engineering using Pandas. The model was trained to predict the most effective drug class based on a patient's genetic mutation profile.

Outcome: Achieved an 87% accuracy rate on the test dataset. Evaluated the model using Confusion Matrices and ROC curves to ensure it didn't falsely predict adverse drug reactions.

Python Scikit-learn Pandas Machine Learning Data Analysis
